On-Device Visual Perception for Light-Weight Browser Agents

A client-side privacy agent built for browser environments (Chrome & Firefox). Sensitive credentials, passwords, and PII are redacted on-device using local DOM & visual models before any screen context is sent to central server VLMs.

Architecture & Key Capabilities

🛡️

1. On-Device Privacy Guard

Manifest V3 extension inspects DOM attributes, input field metadata, and regex patterns to mask password fields, credit card credentials, Aadhaar IDs, and PII directly on user hardware.

🧠

2. Privacy-Preserving VLM Server

FastAPI central server accepts ONLY sanitized/blacked-out screen frames, verifies zero-PII leakage, and determines the next autonomous UI action (click, scroll, type).

⚡

3. Low-Latency Client Execution

Sub-15ms client processing latency using native WebGL/Canvas APIs to guarantee real-time user assistance without performance degradation.
